# LunarRoverUI
A UI for viewing and managing autonomous lunar rovers. This UI is created by a team of Rutgers students, the Lunar project is in collaboration with students from Rowan.

## how to run this

### prerequisites
- Qt framework
- C++ compiler (I am using GCC)

### building
1. navigate to the project directory
2. run: `mkdir build && cd build`
3. run: `cmake .. && make`
4. the executable will be created in the build directory

### running
1. navigate to the build directory
2. run: `./LunarRoverUI`
